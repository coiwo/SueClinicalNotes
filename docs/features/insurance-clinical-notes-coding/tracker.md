## 计划验收用例（全部未运行）

| 用例 | 预期行为 |
|---|---|
| T01 来源及 plan 不匹配 | 未确认来源、未知生效期、另一 plan、未来/过期政策只显示状态；不自动必填或认定拒付 |
| T02 来源冲突 | 显示两个版本与冲突，等待人工确认，不静默覆盖 |
| T03 功能描述 | “能碰到膝盖”保持功能表述与正确的信息来源；没有角度、疼痛分数或因果新增 |
| T04 缺项与恶化 | 无评分/ROM/反应时缺项可见；不变、加重都能保存，未复测不复制历史发现 |
| T05 翻译/语音 | 中英混合、否定、侧别、数字、纠错与转写失败；无同意不发送内容；原文可追回 |
| T06 时间 | 虚构的 30 分钟就诊不能容纳 999 分钟接触；留针不当接触；重叠不双算；未知不补值 |
| T07 CPT | 有/无电刺激、追加接触与再次进针分别测试；首段不是初诊；不因历史选码自动选择；阈值与组合仅按已核实来源检查 |
| T08 诊断 | 未确认诊断只有浏览无诊断建议；未给侧别不猜；不按覆盖排序替换诊断 |
| T09 ICD 日期 | 2026-09-30 与 10-01 使用正确版本；旧记录快照保留；未知代码与不完整代码清楚提示 |
| T10 保存与导出 | 输入/编码改变后旧草稿失效；保存、刷新、重启、复制、PDF 的内容与批准版本一致 |
| T11 历史保护 | 修改不加诊疗次数；并发编辑不丢失；旧版本不能绕过审核定稿；定稿更正保留原因与原文 |
| T12 界面与访问 | 桌面/窄屏操作；退出后页面/API 拒绝访问；画面、fixture 和测试产物无真实身份或完整病例 |
