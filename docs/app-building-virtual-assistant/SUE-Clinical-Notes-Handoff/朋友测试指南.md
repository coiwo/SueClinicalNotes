# 朋友测试指南

## 当前能测试什么

密码首次设置、登录/退出、病人列表与搜索、日期切换、草稿阅读、原文视图和复制，以及数据库的版本/定稿保护。

目前不能新增或编辑病历、连接 Square、AI 生成、打印完整正式 PDF 或远程部署。这不是缺失操作入口的偶发故障，而是尚未开发。登录与定稿保护是开发验证，不构成生产安全审计。

## 在自己的电脑独立运行

需要 Node.js 24 LTS、npm 和首次安装时的网络。现阶段无需 Docker。不要把此包部署到公网，也不要输入真实患者资料。

1. 解压，进入 app 文件夹，在终端打开此文件夹。
2. 创建自己的环境文件：Mac/Linux 运行 cp .env.example .env；Windows PowerShell 运行 Copy-Item .env.example .env。
3. 按顺序运行以下命令，某一步报错就先停下来记录错误：

    npm ci
    npx prisma migrate deploy
    npm run db:seed
    npm run typecheck
    npm run db:verify
    npm run test:access
    npm run dev

4. 在浏览器打开 http://127.0.0.1:3000/login。首次设置自己的测试密码（12–128 个字符），然后使用该密码登录。
5. 应看到 4 位虚构病人，每人 3 次诊疗，合计 12 份简短草稿。这个包不含 Sue 的去身份 Word 样本，因此不会出现该样本的第五位病人。
6. 测完可在终端按 Control+C 停止。重新 npm run dev 后记录与测试密码应仍存在。

如 3000 端口被占用，运行 npm run dev -- --port 3002，浏览器同步使用 3002。以后如需研究样本章节显示，应另做明确标注的完全虚构样本，不复制 Sue 的临床资料。

## 手工检查清单

| 项目 | 操作与预期 |
| --- | --- |
| 未登录保护 | 无痕窗口访问首页，应进入登录页，不能看到病历正文 |
| 首次设置 | 两次密码不一致应提示；设置成功后要求登录；不能重复覆盖已设密码 |
| 密码错误 | 输入错密码提示错误；连续 5 次错误锁定约 15 分钟，会暂时影响共享账号其他尝试，请最后再测 |
| 登录成功 | 正确密码进入墨绿色工作台 |
| 搜索 | 按 DEMO-ONLY-001、Low back、Aetna 等筛选；无匹配时显示空状态 |
| 切换病人 | 日期列表和疼痛摘要随病人更新 |
| 切换日期 | 001 病人三次评分分别为 7、5、4；原始日期按顺序为 09-01、09-08、09-15 |
| 缺失数值 | 004 病人最新评分为空，不应被误显示为 0 |
| 原文和复制 | 复制内容与原文一致，并带 DRAFT 提示；不要把临床资料粘贴到反馈中 |
| 退出 | 退出后再访问首页仍需登录；旧会话不能继续访问 |
| 手机布局 | 缩小窗口或设备模拟，检查文本、搜索、切换与按钮不被遮挡 |
| 重启保留 | 停止再启动后，记录和密码配置仍存在 |
