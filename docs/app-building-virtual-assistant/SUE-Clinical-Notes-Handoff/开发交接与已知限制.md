# 开发交接与已知限制

## 当前实现

Next.js 15.5.26（实际安装版本，以 package-lock.json 为准）、React 19、TypeScript、Tailwind 4、Prisma 6.19.3、SQLite。create-t3-app 脚手架中的 NextAuth 依赖和账号表仍保留；当前实际登录为自定义单共享密码方案，原 NextAuth 路由返回 404。不能按依赖存在推断 Google 登录已实现。

核心文件：src/app/page.tsx（鉴权后读取演示记录）；src/app/workspace.tsx（只读工作台）；src/styles/globals.css；src/server/access-store.ts（本地凭据/会话/限流）；src/app/api/access/[action]/route.ts；prisma/schema.prisma 与 migrations；prisma/seed.mjs、verify.mjs；tests/access.test.mjs。

## 数据与迁移

一次 Encounter 对应多个 Visit 版本，避免把版本计为治疗次数。临床日期存 YYYY-MM-DD 字符串，尚需在将来的输入服务层做有效日历日期校验。只读首页当前只查询 isDemo=true。

SQLite 迁移含手写触发器：保护疼痛范围、病历版本、定稿不可修改/删除、addendum 同诊疗引用及原因、病人归档。使用 migrate deploy；不要用 db push 覆盖这些约束。自动迁移曾生成未加引号的 JSON 空默认值，已手动修正并成功应用。后续迁移必须复核触发器保留。

## 认证设计与限制

storage/private/access.json 保存加盐 scrypt 哈希、会话令牌哈希、失败次数与锁定时间，文件权限 0600。无明文密码。所有 storage 文件被 Git 忽略。密码设置仅开发 loopback origin 开放，已有密码不可通过 setup 覆盖。

会话 cookie 为 HttpOnly、SameSite=Strict；生产 Secure；空闲 2 小时、绝对 12 小时。连续 5 次错误锁定 15 分钟。POST 校验 Origin/Host，非 loopback 需配置 APP_ORIGIN。

限流和会话的并发写队列仅针对单 Node 进程；不适合多实例生产部署。首次设置的可访问性假设服务器仅绑定 loopback；不能把这套未初始化服务暴露给网络。真实服务器上线前必须另行审计 TLS、代理、来源校验、单机/多机存储、备份、恢复、共享账号权限和数据协议。不能承诺 HIPAA 合规。

目前只有首页包含 requireAccess；未来所有服务端数据查询、动作和接口必须显式鉴权。页面级检查不能代替 API 权限检查。Prisma Studio 是独立开发工具，不受本应用登录保护，已在 Sue 本机关闭；不要对外开放。

## 样本与界面注意

Sue 认可当前墨绿色+米白、病人列表、日期、分章节病历和表格风格。请沿用。正文没有经过 AI 临床改写。界面中文与英文混合，正式病历应纯英文；当前复制为来源文本，不提供中文自动翻译。

本包仅 4 人的简单虚构记录，章节解析器面向已有标签，不是通用 Word/PDF 解析。样本表格目前从本地 sample.json 读取，也不是通用数据库附件机制。临床数据和原始样本不在本包，import-demo 脚本没有对应文件时不能运行。也不要将规则依据标记当作已核验政策。
